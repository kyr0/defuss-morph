JSX without a build step: h(), <Reactive>, refs

A JSX compiler turns <p class="x">Hi</p> into jsx("p", { class: "x", children: "Hi" }). Without a compiler, h("p", { class: "x" }, "Hi") builds the same VNode, so every pattern below reads like its JSX version, one call per tag.

1. <Reactive>: re-render on a store change

2. Ref: reach the rendered element

3. forwardRef: a parent controls a component through its ref
