Reactive HTML: a store re-renders markup

reactive({ store, render }, element) renders an HTML string now and again on every store change, by morphing it in: the rows that stay are the same nodes, with what you typed into them. defuss-query adds the same as df$(selector).reactive() for markup that is already in the page.

1. reactive(): a todo list from a defuss-store store

    Type a note next to a todo, then tick, add or sort: each keyed row moves with its note.
